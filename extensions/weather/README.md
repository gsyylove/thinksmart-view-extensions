# 本地天气模块

在首页顶栏音乐入口前显示天气图标、当前温度、天气和今日高低温；点击展开详情，上排每 3 小时预报，下排七天预报。卡片高度 52px、圆角 17px，沿用主题蓝灰底白字，与原系统设置按钮垂直对齐；原系统待机和设置不改动。界面提供刷新和关闭按钮，并隐藏原右上角小时间。完整安装见[项目首页](../../README.md)，来源与服务链接见[第三方说明](../../THIRD_PARTY.md)。

2026-11-08 已在半格系统层 0.2.1、客户端 0.1.6 的两台设备验证，更新后天气静态资源、实况及详细预报接口正常。

## 自动定位与数据来源

1. 读取 [IP138](https://www.ip138.com/) 首页的[公开本机 IP 组件](https://2026.ip138.com/)，提取省、市及可用区县。
2. 通过[中国天气网城市搜索](https://toy1.weather.com.cn/search)匹配天气编号，并校验省份及所属城市编号。区县匹配失败时使用 IP138 所在城市。
3. IP138 获取或匹配失败时，使用[腾讯新闻城市接口](https://r.inews.qq.com/api/ip2city)作为后备。
4. 依据运行时城市编号读取[中国天气网](https://www.weather.com.cn/)实况、当天和七天／小时预报。

无需手填城市，无需天气或定位 Key。当前使用 IP138 公开页面，不使用其需要 Token 的正式 API。组件入口含年份，跨年或页面改版可能需要调整。以上网页及非正式接口不保证长期稳定。

按设备网络出口定位，可能落在运营商或代理出口城市，不保证区县精度。定位失败时不猜测默认城市。服务方能看到请求设备的出口 IP；模块不保存或返回公网 IP，设备界面会显示定位后的地名。公开示例不包含实际个人位置。

## 缓存与有效性

天气正常缓存 30 分钟，缓存到期后重新定位并获取天气。手动刷新最短间隔一分钟。当天预报检查发布日期；实况检查天气站编号、当天日期、三小时内观测时间及温度范围。实况失败时明确显示暂不可用，保留当天预报；小时和七天数据独立获取，失败不阻止当天预报。

更新失败时界面可能保留上次成功数据，并显示更新失败提示。语音会再次检查数据日期与观测时间，过期或获取失败时提示暂不可用。

## 本地语音播报

支持“现在的天气怎么样”“今天天气如何”“现在多少度”“播报一下天气”等明确的本地问题。识别文字后直接读取同一份首页天气数据，固定模板生成回复，跳过大模型。

只播报当前天气、气温及今日最低／最高温，不念观测时间或数据来源；这些信息仍保留在界面。其他城市、未来日期及解释类问题沿用原来的网关路由。天气不采用音乐模块的单次交互规则，聊天监听方式沿用原客户端配置。

## 安装与维护

在本仓库根目录运行：

```bash
bash install.sh weather
```

模块安装在 `/opt/thinksmart/extensions/weather`，`install.py` 挂接页面、客户端数据路由和网关语音入口。当前依赖客户端和网关已有的 aiohttp。官方组件更新前先运行 `bash uninstall.sh weather`，更新后再运行安装命令。

备份在 `/home/ubuntu/thinksmart-backups`。`backend.py` 负责定位与预报解析，`voice.py` 负责本地语音分流，`weather.js`／`weather.css` 负责界面。安装脚本会读取客户端 `current` 所指版本并核对挂接位置；结构变化时停止安装，需重新检查适配。

已在设备验证区县天气匹配、实况及小时／七天预报。定位解析、归属校验和后备路径测试见仓库 `tests/test_weather_location.py`；尚未覆盖所有省市区和海外出口。
