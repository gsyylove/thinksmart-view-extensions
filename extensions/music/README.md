# QQ 音乐模块

音乐扩展版本：**0.1.1**。与天气 0.1.1 联合发布，标签 `m0.1.1-w0.1.1`。

在半格 ThinkSmart View 首页嵌入音乐播放，通过本地规则处理音乐语音指令。完整安装见[项目首页](../../README.md)，来源、许可和服务链接见[第三方说明](../../THIRD_PARTY.md)。

2026-11-08 已在半格系统层 0.2.1、客户端 0.1.6 验证并部署两台；升级保留音乐登录状态。

## 登录与账号

点击首页“音乐”，选择 QQ 或微信扫码，在手机确认后即可访问账号歌单及有权播放的音乐。实际接入 [L-1124/QQMusicApi](https://github.com/L-1124/QQMusicApi)，固定版本见 [requirements.txt](requirements.txt)。当前没有使用 QQ 音乐官方开发者应用接口，也未接入网易云音乐。

音乐服务监听 `127.0.0.1:8091`。模块在 `/opt/thinksmart/extensions/music`，依赖环境在 `~/thinksmart-music/venv`。扫码凭据保存于 `~/thinksmart-music/state/credential.json`，目录权限 700、文件权限 600；不提供凭据读取接口，不记录 HTTP 访问日志。不要上传 `state` 目录。

## 语音播放与队列

先唤醒“小麦小麦”，再说指令。

| 指令 | 来源与队列 |
| --- | --- |
| 播放音乐／随机播放音乐／随便放点歌 | 热歌榜前 100 首打乱播放，同一轮依次切换 |
| 播放热门音乐／播放热歌榜 | 按热歌榜顺序播放 |
| 播放推荐音乐／播放猜你喜欢 | 账号猜你喜欢，当前实测一次返回 5 首 |
| 播放我的歌单 | 从第一个非空个人歌单开始；也可手动选其他歌单 |
| 播放周杰伦的晴天／我想听稻香 | 按歌手和歌名搜索，搜索队列最多 20 首 |
| 暂停音乐／继续播放 | 暂停或继续当前歌曲；无当前歌曲时开始随机热歌 |
| 上一首／下一首／换一首 | 在当前队列切歌 |
| 停止音乐 | 停止播放并恢复完整对话区 |
| 打开音乐 | 打开已有播放视图或音乐选择面板 |

歌曲结束自动下一首，队列尾部循环。重新说“播放音乐”会重新获取并打乱热歌榜。随机范围为榜单，不是整个 QQ 曲库。个人歌单保持分页读取，手动选歌与语音切歌共用队列。

点播明确匹配歌名和歌手时自动播放；有多个候选且没有明确匹配时，播报并自动播放排序第一首，其余候选保留在播放列表中。歌名含“的”时，可说或输入“播放《歌名》”明确整首歌名。当前不借助大模型纠正识别错字。播放地址使用账号可获得的 MP3 320kbps，会员也可能遇到数字专辑、音质或版权权限限制。不可播放时可重新唤醒后说“下一首”。

## 一次指令，一次唤醒

识别文字后，本地规则在大模型意图分析前处理音乐操作；执行后沿用网关 TTS 播报结果，再使用网关的 `close_after_chat` 结束会话。打开、点歌、切歌、暂停、继续、停止和失败提示都按此规则处理。TTS 不可用时直接结束本轮。

回复结束后不再上传麦克风音频，下一条指令需重新唤醒。音乐播放器和本地唤醒词检测继续运行。普通聊天不受这条音乐规则影响。语音识别和合成仍沿用原网关配置，未必离线。

## 首页播放器

播放器在右侧原对话区上方占 75%，下方 25% 保留滚动对话。默认显示封面，点击翻转到同步歌词，再点击返回；每首新歌恢复封面。支持图标按钮和细线进度拖动。封面或歌词不可用时显示对应提示，不阻止音频播放。

“收起”只收起播放视图，音乐继续；“停止音乐”才停止并恢复完整对话区。唤醒、识别和回复期间音乐降低音量，回到待机后恢复。顶部音乐按钮固定宽 200px、高 40px、圆角 12px，播放时滚动显示歌手和歌名，暂停时恢复音乐入口；切歌不改变按钮宽度。

## 安装与维护

在本仓库根目录运行：

```bash
bash install.sh music
```

模块位于 `/opt/thinksmart/extensions/music`。安装器迁移旧挂接后，由 systemd 配置启用运行时加载器。可直接使用官方设置页检查更新。上游文件摘要变化时，对应入口回到官方实现，待扩展适配后恢复。

使用 `bash uninstall.sh music` 可关闭此模块。旧版迁移备份位于 `/home/ubuntu/thinksmart-backups`。


## 验证与限制

已验证扫码、个人歌单、热歌榜、猜你喜欢、搜索、控制指令及回复后待机；浏览器用例覆盖当前队列点选、高亮、随机顺序、队尾循环、自动首选、多候选保留、滚动歌曲信息及进度时间。测试命令与验证边界见[测试说明](../../tests/README.md)。真实唤醒和识别效果需结合设备环境观察，社区接口变化时可能需要调整。

## 当前播放列表

播放器进度条下方同一行显示：当前时间、上一首、播放／暂停、下一首、总时长。两侧时间为 20px 的 `m:ss`，控制按钮居中，随播放和拖动更新时间。标题栏右侧依次为“播放列表”“收起”。

播放器右上角“播放列表”可查看热歌榜、随机播放、猜你喜欢、搜索或个人歌单的当前队列，点击任意曲目切歌。随机队列按实际播放顺序显示，当前曲目高亮。个人歌单仅展示当前加载页，继续选其他页可点“我的歌单”。
