## 音乐扩展 0.1.0

- QQ／微信扫码登录，访问个人歌单、热歌榜及账号推荐，支持按歌手和歌名点歌。
- 热歌榜顺序或随机播放，支持上一首、下一首、暂停、继续、停止及播完自动切歌。
- 当前播放列表展示实际队列，支持点选和当前曲目高亮；随机队列展示打乱后的顺序，个人歌单保留分页。
- 点歌返回多个候选且没有明确匹配时，正常播报并自动播放第一首，其余候选保留在列表中。
- 首页音乐入口滚动显示歌手、歌名，播放器支持封面／同步歌词切换及进度拖动。
- 进度条下方同排显示当前时间、上一首、播放／暂停、下一首和总时长；两侧时间为 20px 的分秒数字。
- 播放器上方依次为“播放列表”“收起”；下方保留对话区。
- 音乐语音操作回复结束后等待重新唤醒，普通聊天沿用原有规则。

## 天气扩展 0.1.0

- 按网络出口自动定位，优先匹配可用区县，失败时按规则降级，不默认猜测城市。
- 展示中国天气网实况、今日高低温、每 3 小时及七天预报，支持手动刷新。
- 明确显示获取失败、过期或不可用状态，实况与详细预报独立降级。
- 支持本地天气语音播报，直接读取天气数据并生成固定回复。
- 顶栏按天气、音乐、原系统待机、设置排列，新增控件配色与尺寸保持协调；原系统待机和设置样式、行为不变。

## 安装

先按半格上游说明安装系统、客户端和网关。在设备上以 `ubuntu` 用户运行以下命令：

```bash
git clone --branch m0.1.0-w0.1.0 https://github.com/gsyylove/thinksmart-view-extensions.git
cd thinksmart-view-extensions
bash install.sh all
```

只装音乐或天气时，将最后一行改为 `bash install.sh music` 或 `bash install.sh weather`。安装需要访问 GitHub 和 Python 包索引，设备需已具备 `~/.local/bin/uv`。

安装器保存挂接文件副本并重启相关服务，当前对话或播放会中断。首次使用音乐需在设备上扫码，天气无需额外申请 Key。

## 上游更新与回退

更新半格客户端、系统层或网关前，先在本仓库目录移除扩展挂接，更新完成后再安装：

```bash
bash uninstall.sh all
# 按上游官方流程更新
bash install.sh all
```

移除操作保留模块文件、挂接文件副本及音乐账号数据，不清除用户配置。若需要回退扩展，先移除当前挂接，再使用目标版本源码重新安装；本次为首次发布，尚无更早的发布标签。

## 验证与已知限制

- 现有 13 项 Python 测试及隔离浏览器功能回归通过。
- 验证覆盖播放队列、自动首选、滚动歌曲信息、进度时间、按钮对齐和横竖屏测试夹具；上游 0.1.6 实际静态页面已检查 1280×800 顶栏无重叠。
- 两台设备部署文件一致，天气与音乐接口及相关服务正常。
- 自动化使用模拟曲目，不等同于真实账号播放权限或现场语音效果；部分歌曲可能受会员、数字专辑、音质或版权限制而不可播放。
- 个人歌单的当前队列展示已加载页；搜索队列最多保留本次 20 条结果。页面重载后不会恢复先前的内存播放队列。
- 天气按网络出口定位，可能对应运营商或代理出口；网页和社区音乐 API 的变更可能影响可用性。

本次发布提供扩展源码，不包含系统镜像、设备备份、API Key、账号凭据或 SSH 密钥。GitHub 将提供对应标签的源码 ZIP 和 tar.gz。
